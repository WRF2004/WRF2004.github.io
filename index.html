AgentFlow

PERSONAL PROJECT

A personal LLM agent platform exploring planning, tool use, and workflow execution with DAGs and checkpoints.

Python · FastAPI · PostgreSQL · Docker
Inside the project

Developed across three iterations: a planner API, a reactive agent with search and Python tools, and a workflow runtime with an execution graph, checkpoints, and a workflow builder. Built with SQLAlchemy, pytest, and Ruff.
